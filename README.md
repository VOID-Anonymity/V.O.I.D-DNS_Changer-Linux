# V.O.I.D™ DNS Changer (Linux Edition) 🛡️

**V.O.I.D™ DNS Changer** — это легковесный и быстрый Bash-скрипт для автоматической оптимизации и смены DNS-серверов в операционных системах семейства Linux. Скрипт анализирует задержку (ping) до популярных узлов и помогает выбрать наиболее подходящий сервер для повышения скорости отклика и обхода сетевых ограничений.

## 🚀 Основные возможности
* **Автоматический замер пинга:** Скрипт тестирует популярные DNS (Google, Cloudflare, Quad9, Xbox-DNS и др.) и предлагает лучший вариант.
* **Игнорирование DNS роутера:** Автоматическая настройка системы на работу в обход стандартных DNS-адресов роутера (например, 192.168.31.1).
* **Поддержка кастомных узлов:** Возможность добавить свой IP или домен для тестирования.
* **Информативный интерфейс:** Центрированный TUI-интерфейс с использованием альтернативного буфера терминала (экран очищается при запуске и восстанавливается при выходе).
* **Безопасность:** Прозрачная работа через `nmcli` (Network Manager).

## 🐧 Поддерживаемые платформы
Скрипт разработан для работы в дистрибутивах на базе:
* **Debian / Ubuntu / Linux Mint** (рекомендуется)
* **Fedora / RHEL / CentOS**
* *Примечание: Для Arch Linux и Gentoo непредусмотрен, читайте вики .*

## 🛠️ Установка и запуск

1. Склонируйте репозиторий:
   ```
   git clone [https://github.com/VOID-Anonymity/V.O.I.D-DNS_Changer-Linux.git]
   cd V.O.I.D-DNS_Changer-Linux
   ```
  Дайте права на выполнение:
      ```
    chmod +x void_dns.sh
      ```
  Запустите скрипт:
     ```
    ./void_dns.sh
     ```
⚠️ Важное примечание

Данный репозиторий предназначен исключительно для Linux-систем.
Для пользователей Windows будет создан отдельный репозиторий с версией на базе PowerShell/Python. Следите за обновлениями в профиле.
